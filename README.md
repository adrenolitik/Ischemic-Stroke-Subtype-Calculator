# Клинический калькулятор ишемического инсульта (TOAST 2.0 + OCSP)

## Обзор проекта
- **Название**: Клинический калькулятор этиологического подтипа ишемического инсульта
- **Цель**: Помощь врачам-неврологам, реаниматологам и специалистам сосудистых центров в определении вероятного этиологического подтипа ишемического инсульта по классификации **TOAST 2.0** и топографической категории по **OCSP** (Oxfordshire Community Stroke Project) на основе клинико-анамнестических данных пациента.
- **Важно**: Инструмент носит вспомогательный консультативный характер и не заменяет врачебного консилиума.

## Функциональность
- ✅ Пошаговый визард ввода данных (5 шагов): демография и факторы риска, дебют и NIHSS, неврологический дефицит (OCSP), гемодинамика/ЭКГ/ЭхоКГ, нейровизуализация (КТ/МРТ)
- ✅ Интерактивный калькулятор шкалы NIHSS (11 доменов)
- ✅ Автоматический расчёт вероятностного распределения между 5 подтипами TOAST: атеротромботический, кардиоэмболический, лакунарный, другой этиологии, неопределённой этиологии
- ✅ Автоматическая топографическая классификация OCSP: TACS / PACS / LACS / POCS
- ✅ Таблица учтённых клинико-диагностических предикторов с весами
- ✅ Клинические рекомендации по антитромботической терапии, статинотерапии, контролю АД и плану дообследования
- ✅ Генерация и печать медицинского заключения (протокола)
- ✅ 4 готовых тестовых клинических примера (кардиоэмболический, лакунарный, атеротромботический, редкая этиология)
- ✅ Сохранение карт пациентов в локальный архив браузера (localStorage) — история расчётов
- ✅ Полностью клиентское приложение — не требует сервера, БД или внешних API, работает без VPN

## Архитектура и данные
- **Стек**: React 19 + TypeScript + Vite + TailwindCSS 4, статическая сборка на Cloudflare Pages
- **Хранение данных**: `localStorage` браузера (ключ `stroke_calculator_saved_cases`) — история сохранённых карт пациентов. Никаких серверных БД не используется.
- **Логика расчёта**: `src/utils/calculator.ts` — весовая модель предикторов TOAST 2.0 и алгоритм классификации OCSP
- **Модели данных**: см. `src/types.ts` (PatientData, CalculationResult, ToastSubtypeInfo, OCSPInfo и др.)

## Как пользоваться
1. Заполните шаги 1–5 (или выберите готовый «Тестовый клинический пример» в верхнем меню)
2. При необходимости используйте встроенный калькулятор NIHSS
3. Нажмите «Сформировать итоговое заключение» или «Показать расчёт» для мгновенного просмотра результата
4. На экране результатов можно сохранить карту пациента, открыть/распечатать медицинское заключение
5. Справочник по классификациям TOAST и OCSP доступен по кнопке «Справочник» в шапке
